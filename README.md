# Sarthak Jagtap — Portfolio

React + Vite portfolio with project links and a WhatsApp enquiry form.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`

## Add your portrait
Put your image in the `public` folder and name it `sarthak.jpg` (`public/sarthak.jpg`). It will appear inside the central orbital sphere. If the image isn't present, the abstract 3D sphere remains visible.

The contact form opens WhatsApp with the submitted details; it does not store submissions on a server.

# Sarthak Jagtap — Developer Portfolio

A modern, responsive developer portfolio built with React.js and Vite, featuring interactive visuals, animations, projects, technical skills, and contact information.

## 🚀 Features

- Modern, responsive portfolio design
- Interactive 3D-inspired visuals
- Smooth animations and transitions
- Featured projects with live demos and GitHub repositories
- Technical skills and experience sections
- WhatsApp contact option
- Resume download button

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Build Tool:** Vite
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Version Control:** Git, GitHub
- **Deployment:** Netlify

## 💻 Run Locally

### Prerequisites
- Node.js (LTS)
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sarthakbuildsdev/sarthak-portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd sarthak-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.

### Production Build

```bash
npm run build
```

The production-ready files will be generated in the `dist` folder.
